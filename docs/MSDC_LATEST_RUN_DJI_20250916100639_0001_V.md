## 4. 结论

1. 最新 run 在 `DJI_20250916100639_0001_V` 上的整体指标是可用的：`MOTA=83.10948`、`IDF1=83.78747`、`HOTA=81.12215`。这条序列的主 USV 目标表现稳定。

2. 空框和重叠框问题在这条序列上没有复现：`zero_area_count=0`，`duplicate_pairs_iou05=0`。这说明输出层 NMS、小框过滤和 stale active 过滤对可视化质量是有效的。

3. GT1 和 GT2 两个主 USV 已经基本稳定，覆盖率都是 `0.9983`，且各自只对应一个输出 ID。这说明 MS-DC-ELT 对持续可见、检测稳定的大目标已经能保住身份。

4. 当前主要短板仍是 GT3 小 UAV/远距目标。它的 high-det 覆盖只有 `0.1615`，low-det 覆盖提升到 `0.6171`，但最终 output 覆盖只有 `0.5072`，且被分裂成 6 个 ID：`3;4;5;7;8;10`。这说明低阈值检测方向有效，但低阈值候选的确认、保活和 lost ID 继承仍不够稳。

5. ROI 重检对这条序列的难目标帮助很小。GT3 的 `roi_low_det_coverage=0.0025`，GT4/GT5 也是 0。这说明当前 ROI 重检更依赖已有稳定轨迹，不能解决长时间没有稳定轨迹种子的远距小目标漏检。

6. 后期 GT4 表现较好，覆盖率 `0.9557` 且只有 1 个 ID；GT5 覆盖率 `0.6788` 且有 2 个 ID。它们进一步说明：低阈值能提升弱目标召回，但在目标短时消失、尺度变化或置信度波动时，ID 继承仍需要加强。

7. 这个 run 只能说明 `Ours-full` 自身当前状态，还不能说明它优于 BoT-SORT/OC-SORT。要下正式对比结论，还需要在同一序列、同一 1797 帧切片上补跑 `botsort` 和 `ocsort` 的 TrackEval。
