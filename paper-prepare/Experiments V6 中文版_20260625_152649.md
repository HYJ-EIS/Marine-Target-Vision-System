# 实验

本节在正式回放设置下评估 MS-DC-ELT v3。主实验结果来自 `results/msdc_paper_phase1/20260624_190710`，补充实验结果来自 `results/msdc_paper_phase1/20260624_190710_supplement_cache_only`。补充实验复用主实验中的检测缓存，重新运行跟踪器并计算 TrackEval 指标。因此，消融、诊断、slice 分析和 sensitivity 分析应理解为缓存回放证据，而不是一次新的检测器完整运行。

所有方法使用相同的 FFCA-YOLO 检测输出。基线跟踪器读取相同的高置信度检测流；MS-DC-ELT v3 额外读取低置信度检测流，用于低置信度观测、证据更新和丢失轨迹处理。本文报告 HOTA、MOTA、IDF1、AssA、IDSW、FP 和 FN。主实验对比不用于证明方法在所有指标上胜出，而是用于识别基于证据的生命周期管理在哪些情况下带来召回收益，以及这些收益伴随怎样的 FP 和身份保持代价。

## 主实验对比

表 1 给出正式主实验结果。在该回放设置下，MS-DC-ELT v3 相比 ByteTrack 获得更高的主要跟踪指标和身份指标。HOTA 从 10.728 提升到 72.512，IDF1 从 6.192 提升到 76.727，AssA 从 2.503 提升到 76.198，IDSW 从 6384 降至 16，FN 从 13515 降至 4710。该收益并非没有代价：FP 从 698 增加到 1809。

与 OC-SORT 和 BoT-SORT 相比，MS-DC-ELT v3 更偏向召回。其 FN 比 OC-SORT 少 329 帧，比 BoT-SORT 少 323 帧。这个召回侧收益伴随更高的 FP 和更弱的身份指标：FP 从 1415 和 1412 增加到 1809，IDF1 从 86.323 和 86.523 降至 76.727，AssA 从 88.462 和 88.900 降至 76.198，IDSW 从 13 和 10 增加到 16。因此，主实验只支持局部召回收益，不支持 MS-DC-ELT v3 相比 OC-SORT 或 BoT-SORT 在整体指标上更优的结论。

| 方法 | HOTA | MOTA | IDF1 | AssA | IDSW | FP | FN |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| FFCA-YOLO + ByteTrack | 10.728 | 29.643 | 6.192 | 2.503 | 6384 | 698 | 13515 |
| FFCA-YOLO + OC-SORT | 77.935 | 77.909 | 86.323 | 88.462 | 13 | 1415 | 5039 |
| FFCA-YOLO + BoT-SORT | 78.138 | 77.950 | 86.523 | 88.900 | 10 | 1412 | 5033 |
| FFCA-YOLO + MS-DC-ELT v3 | 72.512 | 77.677 | 76.727 | 76.198 | 16 | 1809 | 4710 |

## 消融实验

表 2 汇总缓存回放消融结果。关闭低置信度候选路径并未损害已评估指标。`no_low_candidate` 变体略微提高 HOTA、MOTA 和 IDF1，将 FP 从 1809 降至 1715，并保持 FN 为 4710 不变，AssA 和 IDSW 也与完整 v3 相同。该结果不支持将低置信度候选确认写作当前配置下整体指标收益的来源。

关闭直接重获会产生混合结果。`no_direct_reacquire` 将 FN 从 4710 降至 4429，但该 FN 降低同时伴随更高 FP、更低 AssA 和更差 IDSW：FP 从 1809 增加到 1888，AssA 从 76.198 降至 75.519，IDSW 从 16 增加到 17。IDF1 仅从 76.727 小幅变化到 76.791。因此，该结果不能支持“直接重获稳定提升跟踪质量”的结论。

关闭低置信度继承在本次实验中没有可测影响：`no_low_inheritance` 在 HOTA、MOTA、IDF1、AssA、IDSW、FP 和 FN 上均与完整 v3 相同。将基于分数的证据更新替换为 `hits_only` 后，可以观察到一个较窄的身份侧权衡。完整 v3 将 AssA 从 75.919 提升到 76.198，并将 IDSW 从 18 降至 16，但相比 `hits_only`，完整 v3 的 HOTA 和 MOTA 更低，FN 和 FP 更高：FN 从 4613 增加到 4710，FP 从 1795 增加到 1809，HOTA 从 72.540 降至 72.512。输出 NMS 和真实检测年龄门控不是本次实验中的主要因素：关闭输出 NMS 只带来边际变化，关闭真实检测年龄门控得到与完整 v3 相同的结果。低观测预算变体在本次回放中也与完整 v3 相同。

## 事件级诊断

事件级诊断解释了为什么需要谨慎处理低置信度机制和丢失轨迹机制的结论。在完整 v3 中，低置信度候选会被创建，但很少被确认：在 `DJI_20250916100639_0001_V` 中创建 8 个、确认 2 个；在 `DJI_20250711140128_0002_V` 中创建 5 个、确认 1 个。对应确认 precision 分别为 0.25 和 0.20。由于当前诊断日志缺少阶段事件到真值重叠的分母，recall 无法计算。

诊断结果没有显示完整 v3 中存在成功的直接重获或低置信度继承事件。重获尝试数、机会数和成功数均为 0，继承机会数也为 0。这与消融实验的解释一致：直接重获和低置信度继承存在于实现中，但当前运行没有展示这些机制的成功恢复事件。

仍有一个诊断信号值得报告。在第一段序列中，关闭直接重获会使 track breaks 从 17 增加到 36。不过，聚合消融结果同时显示 FN 更低、FP 更高、AssA 更低且 IDSW 更高。因此，这一现象应写作诊断层面的权衡，而不能写作直接重获提升整体身份保持能力的证据。

## 短漏检片段分析

短漏检片段分析不支持完整 v3 的正向泛化结论。在 `DJI_20250711140128_0002_V` 中，所有变体在选出的两个 slice 上均得到 0 HOTA、0 IDF1、0 AssA 和 0 MOTA，同时产生 12 个 FN 且没有 FP。这说明当前跟踪器变体未能恢复这些短漏检片段。

在 `DJI_20250916100639_0001_V` 中，完整 v3 得到 HOTA 64.470、IDF1 66.790、AssA 67.356、MOTA 60.423、IDSW 4、FP 2 和 FN 125。`hits_only` 变体的 HOTA、IDF1 和 AssA 更高，但 FN 更差：HOTA 提升到 69.695，IDF1 提升到 72.207，AssA 提升到 74.504，同时 FN 从 125 增加到 152；FP 保持为 2，IDSW 保持为 4。因此，相比 `hits_only`，完整 v3 在该 slice 上降低了 FN，但该 FN 降低伴随更弱的 HOTA、IDF1 和 AssA。slice 结果具有序列依赖性，应作为错误分析结果使用，不应作为短漏检片段恢复能力的正向证据。

## 敏感性分析

敏感性分析显示，若干参数影响有限，而直接重获分数阈值影响较大。将低置信度确认的最小命中数从 4 改为 6 后，指标几乎相同。将低置信度继承分数从 0.32 改为 0.48 没有影响，这与诊断结果中继承机会数为 0 一致。

证据衰减因子控制身份指标和漏检之间的权衡。将 evidence alpha 降至 0.68 会将 AssA 提升到 78.315、IDF1 提升到 77.526，并将 IDSW 降至 1，但 FN 从 4710 大幅增加到 5781，同时 FP 降至 1476。将 alpha 增加到 1.02 会使 FN 从 4710 小幅降至 4631，但 FP 从 1809 增加到 1823，IDF1 从 76.727 降至 76.610，AssA 从 76.198 降至 75.968，IDSW 从 16 增加到 18。

直接重获分数阈值是当前扫描中影响最大的参数。设置 `MSDC_REACQUIRE_SCORE=1.2` 后，HOTA 提升到 77.970，IDF1 提升到 85.662，AssA 提升到 88.308，同时 FN 从 4710 降至 4682。与其他变体不同，这里的 FN 降低没有带来 FP 代价：FP 保持为 1809，IDSW 从 16 改善到 15。不过，这只是一个 sensitivity 点，不是默认 v3 配置。它应被表述为默认阈值可能偏保守的证据，并提示调参后的变体需要单独正式评测。

## 运行速度与阶段耗时

运行速度在一个 5400 帧、3840 x 2160 分辨率的视频上测量。MS-DC-ELT v3 处理 5400 帧耗时 668.339 秒，对应 8.080 FPS 和 123.766 ms 平均延迟。在本次运行中，它慢于 8.805 FPS 的 ByteTrack，快于 7.689 FPS 的 OC-SORT，也快于 5.503 FPS 的 BoT-SORT。

生命周期更新本身相对检测开销较小。MS-DC-ELT v3 每帧在 MS-DC 更新中耗时 1.391 ms，其中证据更新耗时 0.896 ms，低观测筛选与预算控制耗时 0.320 ms，观测构建耗时 0.042 ms，输出/NMS 耗时 0.112 ms。主要开销来自低阈值检测，每帧耗时 94.786 ms；其次是视频读取/解码，每帧耗时 27.482 ms。这些结果支持生命周期模块本身的效率结论，但不支持跨数据集、广义实时性的结论。

## 支持的结论

实验支持三个结论。第一，在该回放设置下，MS-DC-ELT v3 相比 ByteTrack 获得更高的主要 MOT 指标和身份指标，但产生更多 FP。第二，相比 OC-SORT 和 BoT-SORT，MS-DC-ELT v3 降低了 FN，但 HOTA、IDF1 和 AssA 更低，IDSW 和 FP 更高。第三，在测量视频上，生命周期更新开销相对检测器运行时间较小。消融、诊断和 slice 分析不支持将低置信度候选确认、默认直接重获或低置信度继承写作当前 v3 配置中的独立性能驱动因素。
